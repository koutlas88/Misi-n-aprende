# Misión Aprende

Juegos didácticos para dos perfiles:

- **Peque (4 años):** contar animales, grupos, colores, formas, juntar frutas y memoria. Todo con voz.
- **Explorador (7 años):** sumas, restas, series, tablas, reloj y **problemas guiados** (elegir si es suma o resta paso a paso).

El progreso (misiones, estrellas, pegatinas, qué habilidades fallan) se guarda en el propio dispositivo. Hay un límite diario de misiones configurable en la **Zona de padres**.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub (por ejemplo `mision-aprende`).
2. Sube **todos** los archivos de esta carpeta a la raíz del repositorio (botón *Add file → Upload files*).
3. Ve a *Settings → Pages*. En *Build and deployment* elige *Deploy from a branch*, rama `main` y carpeta `/ (root)`. Guarda.
4. En uno o dos minutos tendrás un enlace del tipo `https://TU-USUARIO.github.io/mision-aprende/`.

## Instalar como app

- **iPhone:** abre el enlace en Safari → botón Compartir → *Añadir a pantalla de inicio*.
- **Windows:** abre el enlace en Edge o Chrome → icono de instalar en la barra de direcciones (o menú → *Instalar*).

## Zona de padres

Desde la pantalla de inicio, *Zona de padres* (pide resolver una multiplicación). Ahí puedes cambiar nombres, ver el registro, el límite diario, desbloquear misiones y hacer copia de seguridad.

## Actualizar la app

Si cambias archivos, sube también un valor nuevo de `CACHE` en `sw.js` (por ejemplo `mision-aprende-v2`) para que los dispositivos descarguen la nueva versión.
